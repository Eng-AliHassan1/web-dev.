STRATEGY DOCUMENTATION

RSI: Wilder RSI(14), calculated from Binance OHLC candles.
V1: 1D uptrend + 1H uptrend + 1H RSI within configured 50–60 range + 30M RSI greater than 1H RSI.
EMA: 9/33 bullish crossover confirmed only on a completed 1H candle.
Order Block: mechanical detector shown on the Order Block page; touch alone never confirms.
Hidden Bull / ICT: bullish RSI divergence candidate around the 30–40 RSI zone. Candidate evidence is shown; no unsupported confirmation is claimed.
Priority alert: tracked asset enters RSI 10–20 or 20–30. Staying in the same zone does not create duplicates.
